# Apoptose vs. Nekrose

Zusammenfassung aus VL 19 (VL-Skript ZUG Teil 2).

| Merkmal | Apoptose | Nekrose |
| --- | --- | --- |
| Art | aktiv, programmiert | (relativ) passiv, unfreiwillig |
| Energie | energieaufwendig | braucht keine zusätzliche Energie |
| Zellgröße | Zelle schrumpft | Zelle schwillt an |
| Membran | bleibt intakt, Blebbing | wird durchlässig |
| Folge | apoptotische Körperchen, Phagozytose | Inhalt wird freigesetzt |
| Entzündung | nein (tolerogen) | ja, Gewebeschaden |

## Signalwege

- **Intrinsisch:** DNA-Schaden, O~2~-Mangel → Bax bildet Poren → Cytochrom c → Caspase-Kaskade
- **Extrinsisch:** Death-Rezeptoren (z. B. durch zytotoxische T-Zellen, NK-Zellen)

## Bcl-2-Familie

- **Anti-apoptotisch:** Bcl-2, Mcl-1, Bcl-xL, Bcl-w, A1
- **Pro-apoptotisch:** Bax, Bak, Puma, Bim, tBid, Bad, Bmf, Noxa

## Merke

- Caspasen: **C**ystein im aktiven Zentrum, spalten nach **Asp**artat
- p53 ist in ca. 50 % aller Tumoren mutiert
- Nekroptose: regulierte Nekrose über RIP1, RIP3 und MLKL, normalerweise durch Caspase-8 blockiert
